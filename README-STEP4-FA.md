# رسانه کتابخانه / رسانه کافی‌نت — بسته تکمیلی گام چهارم

این ZIP **پچ گام چهارم** است، نه پروژه مستقل و نه فایل APK. فایل‌های گام‌های ۱، ۲ و ۳ از قبل باید در پروژه `resaneh_media` وجود داشته باشند.

## نصب

۱. از نسخه فعلی پروژه نسخه پشتیبان یا Git commit تهیه کنید.

۲. فایل‌ها و پوشه‌های این ZIP را با حفظ مسیر، در ریشه پروژه قرار دهید. اگر قبلاً فایل هم‌نامی وجود داشته، نسخه موجود را جایگزین کنید.

۳. وجود وابستگی‌های زیر در بخش `dependencies` از `pubspec.yaml` ضروری است:

```yaml
file_picker: ^13.4.0
receive_sharing_intent: ^1.9.0
share_plus: ^13.3.1
cross_file: ^0.4.0
open_filex: ^5.0.0
video_player: ^2.14.1
path_provider: ^2.1.6
path: ^1.9.1
mime: ^2.1.0
uuid: ^4.6.0
provider: ^6.1.5+1
```

۴. کد `MainActivity.kt` و `VaultService` گام دوم، همچنین `MediaItem`، `TagRepository`، `MediaRepository`، `JalaliFormatter` و `MediaDetailsSheet` گام‌های قبل باید حضور داشته باشند.

۵. بررسی و اجرای هر Flavor:

```bash
flutter pub get
dart format lib
flutter analyze
flutter run --flavor ketabkhaneh -t lib/main_ketabkhaneh.dart
flutter run --flavor kafinet -t lib/main_kafinet.dart
```

اگر فایل `test/widget_test.dart` نمونه پیش‌فرض Flutter هنوز وجود دارد، آن را با تست واقعی اپ جایگزین یا حذف کنید؛ تست اولیه Counter با این پروژه ارتباطی ندارد.

## قابلیت‌های تکمیل‌شده در کد

- انتخاب چند فایل با File Picker 13.x و کپی به Staging خصوصی.
- دریافت SEND / SEND_MULTIPLE با `receive_sharing_intent`، آماده‌سازی فایل و باز کردن صفحه وارد کردن.
- نام و عنوان اختصاصی هر فایل، توضیحات و برچسب‌های مشترک؛ انتخاب برچسب‌های قبلی.
- ذخیره در Vault مطابق کد گام دوم.
- نمایشگر عکس با زوم، پخش‌کننده ویدیو، باز کردن PDF/سایر فایل‌ها در برنامه خارجی.
- Share، پین، ویرایش مشخصات، حذف با تأیید.
- صفحه‌بندی ۱۰۰تایی، فیلتر و جستجو.

## سناریوهای ضروری کنترل روی Android واقعی

۱. انتخاب یک JPG، یک PDF، یک Word و یک ویدیوی MP4؛ بررسی ذخیره هر چهار مورد.
۲. حذف نسخه اصلی از Downloads/Gallery؛ باز کردن نسخه Vault مجدداً.
۳. ارسال یک فایل و سپس چند فایل از Telegram/Eitaa/Files با Android Share Sheet.
۴. بستن فرم بدون ذخیره؛ اطمینان از حذف فایل‌های موقت و باقی ماندن فایل اصلی.
۵. ایجاد دو برچسب «يارانه» و «یارانه»؛ بررسی نبود رکورد تکراری و نتیجه جستجو.
۶. ویرایش عنوان، پین، اشتراک‌گذاری و حذف؛ بررسی حذف رکورد و فایل داخلی.
۷. نصب هم‌زمان دو Flavor و بررسی تفکیک کامل دیتابیس و فایل‌ها.
۸. آزمایش فایل‌های حجیم، کمبود حافظه و فرمت‌های تصویری پشتیبانی‌نشده.

## محدودیت‌ها و مسائل باز

- این بسته در محیط حاضر با Flutter SDK واقعی **بیلد و تست نشده** است و تأیید صفر خطا/نصب APK امکان‌پذیر نیست.
- ClipBox، Backup/Restore، PIN، تنظیمات تم و Factory Reset متعلق به گام پنجم هستند.
- آیکون‌ها، Splash اختصاصی و GitHub Actions متعلق به گام ششم هستند.
- اگر ذخیره یا حذف فایل بین عملیات فایل‌سیستم و SQLite قطع شود، برای پاکسازی فایل‌های یتیم به ابزار نگهداری در گام پنجم نیاز است.
- متن‌های اشتراکی فعلاً به Clipboard کپی می‌شوند؛ ذخیره مستقیم آن‌ها در ClipBox در گام پنجم انجام می‌شود.
- رمزگذاری فایل‌ها (encryption at rest) در این بسته انجام نشده؛ فضای خصوصی برنامه به‌معنای رمزگذاری مستقل نیست.
- پذیرش Share یا Open خارجی در برنامه‌های مقصد به پشتیبانی آن برنامه‌ها از MIME Type بستگی دارد.
